Source Manager

Plugin opcional para Game Access. Agrega fuentes de descarga a tu biblioteca. Es software libre de terceros y no tiene relación con el proyecto Game Access.

Instalar con un clic

Con Game Access instalado, este botón lo abre y te pide confirmación antes de instalar el plugin. Después tenés que volver a abrir Game Access.

Instalar en Game Access

Si no pasa nada, Game Access todavía no está instalado o necesita abrirse una vez para registrar el enlace.

Instalación manual

Descargá el instalador desde la página de Releases y ejecutalo. Windows puede mostrar un aviso porque el archivo no está firmado.

Antes de instalar

  • Un plugin es un programa que Game Access ejecuta en tu equipo. Instalalo solo si confiás en quien lo publica.
  • El enlace verifica la firma SHA-256 del archivo: si no coincide, no se instala nada.
